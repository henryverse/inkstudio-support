# Pip and Orbit provenance

## Originality

Pip and Orbit were created for this project as original procedural 3D models.
The repository's generator script (`make_glb.py`) begins with the statement
that it builds original demo GLB models, and contains the geometry definitions
for both subjects. The models were introduced by the same source commit:

`944580691e296c8c455ee55c01f0fc52e7df9eac`

The script reproduces both published files byte-for-byte. The published hashes
are:

- Pip: `add83cd01d375ee6ebd999be9a3dbd4fb4ca2af4e4ade842f0c7e74c4b4e473b`
- Orbit: `83738d56846eb600760bf1646fab237528df0cc12356aa6281e72e5c8c934d90`

The files are self-contained glTF 2.0 binaries. They contain no embedded
images, textures, external buffer references, or third-party character scans.
Their meshes are built from the original procedural primitives in the generator
script.

This provenance establishes the project source of the files. It is not a legal
opinion or a worldwide originality search.
